 Event Management System
A web-based Event Management System developed as a learning project to understand frontend-backend integration and browser storage handling.

- Features

- User Registration & Login
- Browse Upcoming Events
- Event Booking System
- Payment Tracking
- Admin Dashboard
- Receipt Generation
- Data Storage using localStorage

 Tech Stack

Frontend:
- HTML
- CSS
- JavaScript
- Bootstrap

Backend:
- Node.js

Storage:
- localStorage (Browser-based storage)


 Project Overview

This project was built to simulate a real-world event management platform where users can register, book events, and track payments. The admin can monitor total enrollments and fee collection.

The main goal of this project was to understand:
- Frontend and Backend interaction
- DOM manipulation
- Data handling
- Basic server-side logic
- Web application structure


 How It Works

1. User registers/login
2. Event list is displayed
3. User books event
4. Booking data is stored in localStorage
5. Admin can view enrollment details

 Future Improvements
